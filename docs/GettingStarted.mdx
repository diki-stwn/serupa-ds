# Getting started

## 1. Install

Install a released version straight from GitHub, pinned to its tag:

```sh
npm install github:diki-stwn/serupa-ds#v9.1.1
```

Pin a tag, never `#main`, so updates reach your project only when you choose. Each release tag is prebuilt, so nothing runs on install.

**Updating:** change the tag and read the [Changelog](?path=/docs/changelog--docs) entries in between. Minor and patch releases never remove anything; major releases list what changed and how to migrate.

## 2. Use it in a React app

Vite, Next.js, Remix or any bundler. React 19 is a peer dependency, so the components use your app's React. The package needs Node 22 or later (working on this repository needs Node 26).

```js
import 'serupa-ds/tokens.css';
import 'serupa-ds/base.css';     // page defaults; skip it when adding the system to an existing app
import 'serupa-ds/bundle.css';   // or components.css, plus utilities.css if you use the classes
import { Button, Field, Input } from 'serupa-ds';

export function SignUp() {
  return (
    <form>
      <Field label="Email" required><Input type="email" /></Field>
      <Button type="submit">Create account</Button>
    </form>
  );
}
```

For router links, set the link component once at startup: `configure({ link: Link })`. For another language, wrap the app in `<SerupaProvider locale="id-ID" labels={idLabels}>` (see [Localization](?path=/docs/guides-localization--docs)). The components render on the server too, and types ship with the package.

## Or on a plain page

```html
<html lang="en" data-brand="blue" data-mode="auto">
<head>
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <script src="dist/theme.js"></script>
  <link rel="stylesheet" href="tokens.css">
  <link rel="stylesheet" href="dist/base.css">
  <link rel="stylesheet" href="dist/bundle.css">
</head>
<body>
  <div id="root"></div>
  <script src="dist/lib/react.production.min.js"></script>
  <script src="dist/lib/react-dom.production.min.js"></script>
  <script src="dist/serupa.iife.js"></script>
  <script>
    const { Button } = window.Serupa;
    ReactDOM.createRoot(document.getElementById('root')).render(React.createElement(Button, null, 'Hello'));
  </script>
</body>
</html>
```

## 3. Pick a theme

`data-theme` on any element picks one of the six themes (`blue-light`, `blue-dark`, `violet-light`, `violet-dark`, `emerald-light`, `emerald-dark`). `theme.js` sets it on the page from `data-brand` and `data-mode`, follows the visitor's light or dark setting, and remembers a choice made with `Serupa.theme.set()`. Load it first in `<head>` so the page never flashes the wrong theme. See [Themes](?path=/docs/foundations-themes--docs).

## 4. Before you ship

- **Trim the CSS.** `bundle.css` carries every utility class (nearly 2 MB). `npx serupa-purge src -o public/bundle.min.css`, which comes with the package, keeps the component styles (about 220 KB) and only the utility classes your code uses. Add `--components` to keep only the styles of the components your code names.
- **Fonts and icons are included.** `tokens.css` loads Inter from the package's `fonts/` folder, and icons are SVGs inside the components. Nothing loads from another server. Every Material Symbol works by name, such as `<Icon name="category" />`.
- **Accessibility comes with the components,** but labels are yours: give every field a `Field` label, every icon-only button an `aria-label`, and check each component's Accessibility notes.

## Working on the system

```sh
npm install
npm run storybook   # these pages, at http://localhost:6006, updating as you edit
npm test            # builds the package and runs every test, including axe in all six themes
npx changeset       # describe your change and pick patch, minor or major
```

Each component lives in `src/components/<Name>/`: the component (`<Name>.tsx`), its styles (`<Name>.css`), its component tokens (`<name>.tokens.json`), its usage guide (`README.md`, shown on its page here), its stories (`<Name>.stories.tsx`), its page (`<Name>.mdx`) and a `preview.html` for the visual tests. Its tests are in `tools/test/`. Write the usage guide from [the template](https://github.com/diki-stwn/serupa-ds/blob/main/docs/usage-guide-template.md) (`docs/usage-guide-template.md`): when to use it, when not to, usage, accessibility, props and component tokens.
