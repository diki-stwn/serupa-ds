Getting started

Serupa styles your app's screens with components. Content written in Markdown, such as this help page, has plain links, bold, emphasis and inline code.

  • Install the package.
  • Import the styles once.
    • Or link the CSS file from a plain page.
  • Render a component.

Install

  1. Run the installer.
  2. Restart the dev server.
npm install serupa-ds
import "serupa-ds/styles.css";
