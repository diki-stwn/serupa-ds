- Added: Input `mask` keeps text in a pattern such as `"9999 9999 9999 9999"`, `"99/99/9999"` or `"AA99 **** **** ****"` as people type, paste or delete. The caret stays after the character it was after, and Backspace or Delete next to the pattern's own text removes the typed character beyond it. A digits-only mask gets the number keyboard on phones.
